Your week, in focus.
A concept, not a client result.

Northstar is a fictional product interface exercise. It has not been built, user-tested, or connected to real team data.

The brief

Imagine a team tool that contains useful information but makes it difficult to see the shape of the week. This exercise considers how a more focused overview could help someone decide where to look next.

The direction

A quiet neutral canvas, a persistent navigation rail, and one prominent visual summary establish the information hierarchy. Secondary elements are deliberately subdued so the primary overview remains easy to scan.

What this concept explores

  • Information hierarchy and visual emphasis in a dashboard
  • A compact navigation pattern for a multi-section tool
  • Using color and spacing to make dense information feel more approachable

Product design starts with real users

Any production interface would need discovery, accessibility checks, real content, and usability testing. These screens are illustrative, not validated product outcomes.
